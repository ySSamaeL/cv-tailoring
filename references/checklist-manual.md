# Checklist manual (quando não dá para rodar os scripts)

Use no Cowork/claude.ai sem execução de código. É a versão humana do que `aderencia.py` e `verificar_fatos.py` fazem; siga linha a linha e diga ao usuário que a verificação foi manual.

## Análise de aderência

- [ ] Localidade e modelo: remoto → ok; presencial/híbrido → só Grande Recife (Recife, Olinda, Jaboatão, Paulista, Camaragibe, Cabo de Santo Agostinho, São Lourenço da Mata, Abreu e Lima, Igarassu, Ipojuca, Moreno, Itamaracá, Itapissuma, Araçoiaba); outra cidade → só com relocação custeada (deslocamento e moradia).
- [ ] Senioridade: júnior ok; sem nível ou pleno → ressalva; sênior/lead/especialista → não aplicar.
- [ ] Cada requisito com status cobre / parcial / lacuna e o trecho literal do perfil (com ID `seção#ordem`).
- [ ] Termos que nunca vão para o currículo mesmo se a vaga pedir: Jira, TestRail/Zephyr/Xray, Azure DevOps, Cypress, Selenium, Puppeteer, Jest/testes unitários, TDD, Cucumber, Java, ISTQB, Docker/Kubernetes, Jenkins e outros CI, JMeter/k6/testes de performance, Grafana/Datadog, GraphQL, MySQL/NoSQL, iOS, Vue/Angular, Storybook, responsividade, acessibilidade web/WCAG, SEO.
- [ ] Recomendação: aplicar / aplicar com ressalvas / não aplicar.
- [ ] Parou e esperou o ok antes do currículo.

## Currículo, linha a linha

- [ ] Cada bullet aponta para uma linha do perfil e diz o mesmo fato (pode trocar vocabulário, não o fato).
- [ ] Cada número do bullet aparece na linha de origem (ou nas seções 11/11b).
- [ ] Nenhum nome de ferramenta, empresa ou sigla que não esteja no perfil.
- [ ] Nenhum verbo de papel que a fonte não sustente (liderei, mentorei, gerenciei, arquitetei, fundei, "sozinho").
- [ ] Sem "apostas"/"betting", sem status da UFRPE, sem "certificação", sem CI/CD rodando, sem "liderei equipe de QA", sem INC-xxx, sem hosts.
- [ ] 8 a 15 palavras-chave técnicas da vaga, todas com cobertura.
- [ ] Idioma da vaga em todo o documento.
- [ ] Cabe em uma página (no Doc: estime ~550 a 650 palavras; acima disso, corte).
