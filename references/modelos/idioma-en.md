## Style

- Start bullets with a past-tense action verb: Built, Automated, Cut, Designed, Structured, Validated, Mapped.
- Numbers in English format: `1,990`, `27,000` (or `27k`), `−90%`, `40 h/month`.
- Translate facts, never upgrade them. "Responsável pela qualidade de" = "Responsible for quality across", not "Head of QA".
- Advanced English: say "Advanced English"; the SAT score (1270, 83rd percentile) is optional evidence for international roles.
- If the verifier fails a true bullet only because of language, add the missing EN→PT word to `references/dicionario-en-pt.txt`; do not lower the bar.
